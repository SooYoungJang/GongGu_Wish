# Google Play 스토어 자산

이 디렉터리는 Android `com.gonggu.wish`의 한국어 기본 스토어 등록정보에 사용하는 최종 업로드 자산을 보관한다.

## 파일

| 파일 | 규격 | 용도 |
| --- | --- | --- |
| `app-icon-512.png` | 512×512, 32-bit PNG, 1 MB 이하 | Play 스토어 앱 아이콘 |
| `feature-graphic-1024x500.png` | 1024×500, 24-bit PNG | 피처 그래픽 |
| `feature-graphic.svg` | 1024×500 | 피처 그래픽 편집 원본 |
| `phone-01-ranking.png` | 1080×1920 PNG | 인기 공구 랭킹 |
| `phone-02-reels.png` | 1080×1920 PNG | 세로형 공구 릴스 |
| `phone-03-detail.png` | 1080×1920 PNG | 공구 상세와 알림 동작 |
| `phone-04-activity.png` | 1080×1920 PNG | 최근 본 공구와 게스트 마이페이지 |

## 출처와 재현 조건

- 앱 아이콘은 `apps/mobile/assets/app-icon.png`를 512×512로 Lanczos 리샘플링한 뒤 알파 채널을 유지한다.
- 피처 그래픽은 앱의 핑크·오렌지·퍼플 색상과 캘린더·상품·릴스 기능을 추상화한 저장소 원본 SVG에서 렌더링한다. 실제 앱 화면처럼 오인할 합성 UI나 외부 이미지가 없다.
- 휴대전화 스크린샷은 2026-07-29 최신 `origin/develop`의 Android Preview Release 빌드를 `GongGu_API_34` 에뮬레이터에서 직접 캡처했다.
- 캡처 빌드는 Preview 백엔드와 Google 테스트 광고 설정을 사용했다. 스크린샷에는 광고나 개인 계정 정보가 노출되지 않는다.
- 공개 업로드 전 현재 제품 데이터와 UI가 스크린샷과 일치하는지 다시 확인한다.

## 권장 대체 텍스트

- `phone-01-ranking.png`: 카테고리와 기간별로 인기 공동구매를 탐색하는 랭킹 화면
- `phone-02-reels.png`: 상품 사진과 가격, 알림과 구매 링크를 한 화면에서 보는 공구 릴스
- `phone-03-detail.png`: 판매자와 상품 정보, 마감 상태 및 알림 기능이 표시된 공구 상세 화면
- `phone-04-activity.png`: 최근 본 공동구매와 로그인 후 이용 가능한 활동 기능을 안내하는 마이페이지
- `feature-graphic-1024x500.png`: 캘린더, 상품 카드와 세로형 영상을 표현한 공구위시의 컬러 일러스트

## 업로드 전 확인

1. 각 파일의 픽셀 크기, PNG 채널 수와 파일 크기 검사를 통과시킨다.
2. 스크린샷에 테스트 식별자, 디버그 오버레이, 광고 실패 문구, 개인 데이터가 없는지 육안 검토한다.
3. Google Play 기본 스토어 등록정보의 한국어 자산에 순서대로 업로드한다.
