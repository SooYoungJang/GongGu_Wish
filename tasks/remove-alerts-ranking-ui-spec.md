# 릴스·제품상세 알림 제거 및 랭킹 배지 정리 명세

## 목표

- 릴스와 제품상세가 공유하는 제품 페이지에서 `인플루언서 알림`과 `브랜드 알림` UI 및 상호작용을 제거한다.
- 랭킹 상위 카드의 `1위 / NEW` 메타 영역을 작은 화면과 큰 글자에서도 잘리지 않는 독립 배지 형태로 정리한다.

## 범위

- `ProductReelPage`의 판매자·브랜드 알림 버튼, 전용 상태·핸들러·스타일을 제거한다.
- 북마크와 제품별 마감 알림은 유지한다.
- 마이페이지·설정의 알림 관리 기능과 랭킹 카드의 제품별 알림은 유지한다.
- 랭킹 순위 원형 배지와 추세 배지를 서로 독립된 표면으로 표시하고, 고정 높이에 의존하지 않게 한다.

## 수용 기준

1. 제품상세와 릴스 어디에서도 `인플루언서 알림`, `브랜드 알림` 컨트롤이 렌더되지 않는다.
2. 제거된 컨트롤이 차지하던 빈 행이나 여백이 남지 않는다.
3. 로그인 게이트는 북마크와 제품별 마감 알림에 계속 적용된다.
4. 랭킹 1위의 `NEW`가 원형 순위 배지와 겹치거나 카드 경계에서 잘리지 않는다.
5. 모바일 단위 테스트, lint, typecheck와 Preview Android 실기기 흐름이 통과한다.

## 비범위

- 알림 preference 데이터/API 삭제
- 랭킹 데이터 계약 변경
- Production 배포
